# Peukku (Y)

Peukku is a free token for friends on the Solana network. Peukku is Finnish slang for thumb, as in thumbs up. In old MSN Messenger, (Y) was the thumbs-up emoticon.

The token has not been created yet. When it is, its address will be added here, and anyone can check the facts below in a blockchain explorer.

## The plan

- Total supply: 1,000,000,000 Peukku. The right to make new tokens will be switched off for good, so nobody can ever make more.
- Nobody can freeze anyone's tokens.
- The creator keeps 100,000,000 (10 %).
- 900,000,000 (90 %) go to a separate friends' wallet. Every friend gets 10,000,000 (1 %) from it, the same amount for everyone.
- It is free. Friends are not asked for money, posts or personal details, only for a public Solana wallet address.

## What it is not

- It is not an investment. It gives no profit, no dividend and no promise that anyone will buy it back.
- It may never have any value.

## Stay safe

Nobody needs your recovery phrase (seed phrase) or private key to send you Peukku. Never give them to anyone.

## Files

- `logo.png`: the token logo, 512 x 512 pixels.
- `token.json`: the token's metadata (name, symbol, description and logo link). The token will point to a fixed version of this file, so later changes in this repository do not change what wallets show.
