# Peukku (Y)

Peukku is a free token for friends on the Solana network. Peukku is Finnish slang for thumb, as in thumbs up. In old MSN Messenger, (Y) was the thumbs-up emoticon.

The token was created on 19 November 2026. Anyone can check the facts below in a blockchain explorer.

- Token address: `CYW6THnJhvqxa2kjxqkiXWEjgw84Nr9kWUvwZ4bC7Y8s`
- Solana Explorer: https://explorer.solana.com/address/CYW6THnJhvqxa2kjxqkiXWEjgw84Nr9kWUvwZ4bC7Y8s
- Solscan: https://solscan.io/token/CYW6THnJhvqxa2kjxqkiXWEjgw84Nr9kWUvwZ4bC7Y8s

## The facts

- Total supply: 1,000,000,000 Peukku. The right to make new tokens was switched off for good, so nobody can ever make more.
- Nobody can freeze anyone's tokens.
- The name, symbol and metadata link are locked for good. Nobody can change them.
- The creator keeps 100,000,000 (10 %).
- 900,000,000 (90 %) are in a separate friends' wallet: `4C3b9FGW2zpxBQt3JrnQ3sNS5TMXrXbwsixVT3xDDhxs`. Every friend gets 10,000,000 (1 %) from it, the same amount for everyone.
- It is free. Friends are not asked for money, posts or personal details, only for a public Solana wallet address.

## What it is not

- It is not an investment. It gives no profit, no dividend and no promise that anyone will buy it back.
- It may never have any value.

## Stay safe

Nobody needs your recovery phrase (seed phrase) or private key to send you Peukku. Never give them to anyone.
